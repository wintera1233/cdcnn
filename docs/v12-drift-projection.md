# v12.0 把漂移方向從輸入裡投影掉

Run：`runs/20261005T145146298993Z_baseline_ladder_full`。四格 × 五個 seed，
leakage audit 通過。GPU 前置閘：`runs/20261005T145128467709Z_baseline_gpu_smoke`。
config：`configs/drift_projection.json`，預測與否證條件在開跑前寫入。
提案：`proposal-v12.md`；第 0 步：`docs/v12-step0-separability.md`；
第 1 步關卡：`runs/20261005T140110659659Z_drift_projection_cv`。

## 做法

在 signed-log → per-sample 之後、進網路之前，`x′ = x − U Uᵀ x`。`U` 從 Batch 1 三種
氣體（Ethanol、Ammonia、Ethylene）各自兩個採集區塊的質心差算出，存進 checkpoint 的
normalizer，`src/evaluate.py` 對每個 target 樣本套同一個映射。四格都不帶擴充、不帶
生成區塊，對照列就是定案基準 `R-fig-logps`。

| 變體 | 拿掉的子空間 | k | 性質 |
|---|---|---:|---|
| `R-proj-axis` | 三個單位化偏移的共同方向（不置中 SVD 第一向量） | 1 | **頭條**，source-only |
| `R-proj-sub3` | 三個偏移張成的空間 | 3 | source-only，不做選擇 |
| `R-proj-eth` | Ethanol 的偏移 | 1 | target-informed：選 Ethanol 是看過 target 才知道的 |

頭條原本是 `sub3`，第 0 步只用 Batch 1 就顯示 `axis` 拿掉的類間變異少得多
（3% 對 76%），在開任何 target 之前改成 `axis`，記錄在 config 的 `projection.headline`。

## 對照事前預測

- **頭條 `R-proj-axis` 不可分辨**：+0.0128 對門檻 0.0145，差 0.0017。否證條件一觸發。
  這是本專案第一個 source-only 的、正的、接近門檻的差，但照事前規則它不是效應。
- **Acetaldehyde 仍是 0.000**：否證條件二觸發。投影掉共用方向之後，九個 target batch
  的 Acetaldehyde 質心仍有七到九個落在 Batch 1 的 Ethanol 上（見下）。
- **`R-proj-eth` 可分辨**（+0.0191 對 0.0162），但它的方向選擇是 target-informed，
  只能當上界。它與 v8.1 的 `R-aug-t2`（+0.0214，同樣 target-informed）相當。
- **逐類別的形狀與擴充一模一樣**：Acetone +0.24 到 +0.27，Ethylene −0.28 到 −0.29。
  提案裡「投影不重新分配預測配額」這句話是錯的：拿掉共用方向與沿共用方向擴充，
  對分類器的效果相同，都是讓它不再用那條軸上的位置做判斷，Acetone 因此得分，
  Ethylene 因此失分，因為 Ethylene 的漂移不在那條軸上，而它與 Acetone 的區分有一
  部分在那條軸上。

## 機制指標：投影拿掉的是什麼

`scripts/measure_projection_drift.py`，在各格自己的正規化（含投影）空間裡量：

| 變體 | 漂移幅度（平均） | 保留 | 類內半徑（平均） | 保留 | 漂移 ÷ 半徑（中位） |
|---|---:|---:|---:|---:|---:|
| `R-fig-logps` | 2.011 | 1.000 | 1.062 | 1.000 | 1.80 |
| `R-proj-axis` | 1.697 | **0.844** | 0.619 | **0.583** | **2.46** |
| `R-proj-sub3` | 1.039 | 0.517 | 0.534 | 0.502 | 1.79 |
| `R-proj-eth` | 1.386 | 0.689 | 0.786 | 0.740 | 1.40 |

三件事：

1. **`axis` 這條軸幾乎不是真實漂移的軸。** 拿掉它只減少 16% 的漂移幅度（能量 29%），
   卻減少 42% 的類內半徑。第 0 步看到的「Batch 1 的類內長條沿著 u」就是這件事：u 裝的
   主要是 Batch 1 內部的濃度散佈加上兩個月的採集偏移，而三年的真實漂移大部分在別處。
   機制指標因此不降反升（1.80 → 2.46），因為分母縮得比分子多。
2. **`sub3` 真的拿掉大半漂移**（能量 73%，與 `drift-geometry.md` 量的 68–81% 一致），
   但也拿掉一半的類內半徑與 76% 的類間變異，結果是類別大洗牌：Toluene +0.53、
   Ethanol −0.34、Ethylene −0.42，淨值只有 +0.0055。
3. **`eth` 拿掉 53% 的漂移能量、26% 的半徑**，是三者裡「漂移對類內」比例最好的，
   這解釋了它為什麼最高。但哪一個偏移最準，是對照 target 才知道的。

Acetaldehyde 的 target 質心最靠近哪個 Batch 1 質心（九個 batch）：

| 變體 | 落點 |
|---|---|
| `R-fig-logps` | Ethanol ×7，Ethylene ×2 |
| `R-proj-axis` | Ethanol ×7，Ethylene ×2 |
| `R-proj-sub3` | Ethanol ×8，Toluene ×1 |
| `R-proj-eth` | Ethanol ×8，Ethylene ×1 |

即使 `sub3` 把漂移能量拿掉 73%，Acetaldehyde 仍落在 Ethanol 上，因為投影後兩者在
Batch 1 裡的距離只剩 1.01 個半徑，殘餘的漂移就夠把它推過去。**死類別不是「沿共用
方向的平移」這一個機制造成的**；`docs/why-acetaldehyde.md` 的解釋需要修正：方向對，
但它與 Ethanol 的距離在扣掉共用方向之後就不夠分。

## 結論

- Batch 1 自己兩個採集區塊的偏移，**可以當方向估計，不能當漂移本身**。它的共同軸只
  裝了 29% 的三年漂移能量，其餘裝的是 Batch 1 內部的散佈。拿掉它，source 的可分性
  不受影響（第 1 步關卡 0.9709 對 0.9680），target 上得到 +0.0128，不可分辨。
- 要拿掉夠多的漂移就得拿掉三維，而那三維裝著 76% 的類間變異；Batch 1 在這個空間裡
  只有兩到三個有效維度，漂移與類別資訊在同一個低維子空間裡糾在一起，投影分不開
  它們。這是這份資料在 source-only 下的結構性限制，和擴充遇到的是同一面牆。
- 唯一可分辨的格 `R-proj-eth` 是 target-informed 上界，與 v8.1 的 `R-aug-t2` 同量級、
  同一種逐類別形狀。兩個完全不同的機制（加樣本、刪座標）給出同樣的結果，代表上限
  來自資料的幾何，不來自方法。
- **source-only 定案數字仍是 0.5556。**

## 混淆項

- 估計器有效與否是對照 target 判定的（`docs/batch1-internal-drift.md` 第三條限制）。
- 投影後不重做 per-sample 標準化，宣告的選擇，沒掃。
- 四格訓練列數與步數相同。
- 機制指標的「半徑」是到質心的平均距離，與 `baseline.md` 5.2 的定義不同。

## 沒做的事

- oracle 上界（用 target 的真實漂移主成分投影）沒跑；它能回答「方向估得完美時的
  天花板」，但要用 target 建轉換，必須分開跑、明確標記。
- 「只拿掉 u 但保留 Batch 1 內部沿 u 的散佈」做不到，投影分不開兩者。
