# v10.0 給 Eq. (14) 加上正負號

Run：`runs/20260929T031927475103Z_baseline_ladder_full`。四格 × 五個 seed，
leakage audit 通過。GPU 前置閘：`runs/20260929T031825784660Z_baseline_gpu_smoke`。
config：`configs/signed_generation.json`，預測與否證條件在開跑前寫入。

## 問題

v9.0 量到論文的特徵生成區塊瞄的軸是對的（7.6% 能量落在漂移張成空間，虛無值的
25 倍），但沿漂移軸對稱位移（有號分量 −7.5%），而且投影到任一條真實漂移軸上的
配對位移只有漂移的 3%。`docs/v9-feature-generation.md` 的結論是「無號的擾動修不了
有號的位移」。v10.0 直接測這句話：給 Eq. (14) 一個正負號，看區塊會不會動。

## 做法

方向來自 Batch 1 自己：Ethanol 兩個採集區塊（`src/augment.py:SOURCE_BLOCKS`，
第 0–84 列與第 248–254 列）推過當下的 stem 之後，在 style 空間（block-3 殘差的逐位置
mean 與 std，各 128 維）取第二區塊減第一區塊的質心差。每個 epoch 開頭重估一次，
因為 stem 本身在訓練。不碰任何 target 檔案。

| 變體 | Eq. (14) | 意思 |
|---|---|---|
| `R-gen` | `μ′ = μ̂ + δ̂·ε` | 論文原版，對稱高斯 |
| `R-gen-sign` | `μ′ = μ̂ + δ̂·\|ε\|·sign(d)` | 只修正負號，幅度照論文 |
| `R-gen-shift` | `μ′ = μ̂ + T·d + δ̂·ε` | 論文噪聲保留，再加 T=2 個區塊偏移的定向位移 |

`δ′` 同式。四格都帶 `R-aug-t2` 的輸入端有方向擴充，`λ_MSE` 0.5、`L_ce` 只作用在
原始分支，與 v9.0 的 `R-gen` 相同；`R-aug-t2` 與 `R-gen` 在本 run 重跑當對照列。

選 Ethanol 而不是三個區塊的平均，是沿用 `R-aug-t2` 的選擇；那個選擇當初是對照
target 定的，所以方向的**選擇**是 target-informed，正負號的**計算**是 source-only。

## 對照事前預測

- **`R-gen-sign` 在門檻以下**：命中。把一個只有漂移 3% 的位移折成正的，它還是 3%。
- **`R-gen-shift` 是唯一可能動的格**，預期落在 +0.00 到 +0.02：實際 +0.0023，
  在範圍內，但**否證條件觸發**：與 `R-gen` 不可分辨。
- **已知風險沒有發生。** config 記錄過一個 target-informed 的舊量測，說 Batch 1 兩個
  採集區塊在 style 空間的方向可能與真實漂移反向（cos −0.692）。事後量
（`scripts/measure_signed_direction.py`，凍結的 `R-gen-shift` seed 1042）：

| 類別 | cos（mean 軸） | cos（std 軸） | 真實漂移 \|d\| | 位移 / 漂移 |
|---|---:|---:|---:|---:|
| Ethanol | +0.769 | +0.774 | 0.0435 | 1.05 |
| Ammonia | +0.558 | +0.553 | 0.0393 | 1.16 |
| Ethylene | +0.305 | +0.326 | 0.0321 | 1.41 |
| Acetaldehyde | +0.596 | +0.635 | 0.0550 | 0.83 |
| Acetone | +0.693 | +0.727 | 0.0475 | 0.96 |
| Toluene | +0.662 | +0.720 | 0.0623 | 0.73 |
| **51 格平均** | **+0.593** | | | |

  隨機方向的虛無值是 1/√128 = 0.088。正負號指向 target，六個類別全部為正，位移
  幅度是真實漂移的 0.73 到 1.41 倍。舊量測的 −0.692 是把區塊當作 Eqs. (12)–(13)
  的「batch」時的散佈方向，不是這裡用的質心差；兩者不是同一個量。三個區塊的平均
  方向 cos +0.338，也是正的，只是比 Ethanol 差。

## 結論

**在 block 3 的 style 空間裡給區塊一個方向正確、幅度與真實漂移同量級的定向位移，
target mean 動 +0.0023，不可分辨。** 這不是「沒對準」，也不是「太小」，兩者都量過
了。這是 style 空間本身的問題：逐位置的 mean 與 std 只張成真實漂移的 30.1%
（v9.0 量的），而且分類器的決策邊界對這個子空間裡的位移不敏感。同樣的定向位移在
輸入端（v8.1）能搬動 Acetone 與 Ethylene 各 0.25 以上，在這裡搬不動任何類別。

這把特徵生成區塊當作機制關掉了：無論 Eq. (14) 有沒有正負號，它能觸及的子空間不是
決策邊界會回應的那一個。

`L_MSE` 在四格都正常下降（`R-gen-shift` 從 0.0055 到 0.0035），網路確實學到了對
定向位移的不變性，一如 v9.0；那個不變性一樣換不到 target 準確率。

## 混淆項

- **四格都帶 `R-aug-t2`**，輸入端已經有一個同方向的定向位移。`R-gen-shift` 量到的是
  在那之上的邊際效應，兩者可能重疊。一個更乾淨的測法是 `R-gen-shift` 不帶輸入擴充
  對 `R-fig-logps`，這次沒跑。
- Ethanol 方向與逐位置 style 軸都是繼承自前幾版的 target-informed 選擇，所以整串仍是
  上界；source-only 定案仍是 `R-fig-logps` 的 0.5556。
- 兩個 signed 格每個 epoch 多一次 445 列的無梯度前向，optimizer 步數與 per-sample
  exposure 四格相同。
- 區塊偏移的模長是 minibatch style 散佈的 0.41 到 0.46 倍（`history.json` 的
  `signed_generation`），所以 `shift` 的 T=2 加的是 0.8 到 0.9 倍噪聲尺度的定向位移。

## 下一步

論文三個元件只剩對比損失 `L_con`（Eq. S5）。它是唯一有不變性機制的元件，而且它需要
的 `(z_f, z̄_f)` 已經在 `forward_pair` 裡。v10.0 之後，`z̄_f` 可以是論文原版、
`sign`、或 `shift` 三種之一，`L_con` 的測試可以順便問「拉近哪一種 z̄_f 有差」。
